The game's battle songs, copied from apps/blood-in-the-sand/assets/audio/music by `bun run sync` (never edit those here). Gitignored. Promo-only beds (music that never ships in the game) can be dropped straight into this folder as .mp3 — the next `bun run sync` lists them after the battle songs. Pick one with the `music` prop (e.g. `--props='{"music":"taiko.mp3","musicFrom":60}'`) or the Desk's music dropdown.
